# VCall - Modern Mobile Video Calling Demo

A simple, clean, modern, student-friendly mobile video calling application built with Flutter.

## 📱 Features Included (10 Screens)
1. **Splash Screen:** Minimal logo, smooth animation, tagline *"Connect with everyone"*.
2. **Login Screen:** Clean rounded inputs, password visibility toggle, forgot password, register link.
3. **Register Screen:** Full name, email, password, and confirm password fields.
4. **Home Screen:** User greeting (*"Good evening, Trí 👋"*), Online now avatars, prominent *"Start a Video Call"* banner, recent calls list, and instant demo incoming call trigger.
5. **Contacts Screen:** 5 contacts (Minh Nguyễn, An Trần, Nam Phạm, Linh Lê, Huy Nguyễn) with live online status and quick call button.
6. **Incoming Video Call Screen:** Clean blurred dark background, large caller avatar, green Accept and red Decline action buttons.
7. **Video Call Screen:** Full-screen remote video, floating Picture-in-Picture (PIP) camera preview, live call duration timer, and touch-friendly controls (Mic, Cam, Speaker, Switch Camera, End Call).
8. **Call Ended Screen:** Summary of call duration, *"Call Again"* and *"Back to Home"* actions.
9. **Call History Screen:** History log with incoming/outgoing/missed icons, timestamp, duration, and direct callback.
10. **Profile Screen:** Profile overview (Nguyễn Hữu Trí), online indicator, and Flutter `ListTile` settings (Edit profile, notifications toggle, dark mode toggle, logout).

## 🚀 Getting Started

### Prerequisites
- Flutter SDK (>= 3.13.0)
- Android Studio / Android Emulator or physical device / Chrome / Windows

### Run the App
```bash
# Get packages
flutter pub get

# Run on connected device / emulator
flutter run
```
